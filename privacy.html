プライバシーポリシー

最終更新日: 2026年10月27日

kirinuki-kun（以下「本ツール」）は、運営者が自分の YouTube チャンネルを管理するために使う個人用ツールです。

取得する情報

本ツールは Google の OAuth 認証を通じて、次の権限を使います。

  • YouTube への動画のアップロード（youtube.upload）
  • YouTube のチャンネル・動画情報の読み取り（youtube.readonly）

情報の使い道

取得した情報は、運営者自身のチャンネルへの動画の投稿と、投稿した動画の情報（再生数など）の確認にだけ使います。

保存と共有

認証情報（トークン）とデータは、運営者の端末にだけ保存します。外部のサーバーに送ったり、第三者に提供・販売したりすることはありません。

本ツールによる Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールへのアクセスを取り消せます。

GitHub Issues からご連絡ください。

Privacy Policy

Last updated: October 27, 2026

kirinuki-kun ("the tool") is a personal tool used by its owner to manage their own YouTube channels.

  • Data accessed: Through Google OAuth, the tool uses the youtube.upload and youtube.readonly scopes.
  • Use: Only to upload videos to the owner's own channels and to read information (such as view counts) about those videos.
  • Storage and sharing: Tokens and data are stored only on the owner's device. They are never sent to external servers, or shared with or sold to third parties.
  • The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: You can revoke access at any time at myaccount.google.com/permissions.
  • Contact: GitHub Issues
